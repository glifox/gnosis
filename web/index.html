Another WYSIWYG
_Markdown_ Editor

Pretext-driven line breaks

This allows full control for where and when to do a line break, adding the possibility to avoid breaks on code blocks and other desired elements.

Less flickering and jumps

Other WYSIWYG markdown editors have big jumps and text movement due to hiding/unhiding markings, that shift the content of the text quite a lot and tends to be very uncomfortable, and other markdown editors completely hide these markings making them closer to a rich text editor. gnosis gets the best of both worlds.

Code-like editing

The advantage of the gnosis implementation is that you get a rich-text-like preview and a code-like text editing experience.

Open Source

Of course, gnosis is Free and Open Source. Check it out on GitHub at glifox/gnosis by feraxhp.
